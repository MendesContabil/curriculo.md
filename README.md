# Leonardo — Portfólio 💼

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido em **React** com **Vite** e **Tailwind CSS**, com foco em desempenho, design limpo e fácil personalização.

🌐 **Demo online:** [leonardos-portfolio-6e94874e.base44.app](https://leonardos-portfolio-6e94874e.base44.app/)

---

## 🚀 Tecnologias utilizadas

- **React** — Interface moderna e reativa
- **Vite** — Build rápido e otimizado
- **Tailwind CSS** — Estilização ágil e responsiva
- **Node.js & npm** — Ambiente de execução e gestão de pacotes

## ⚙️ Instalação e execução local

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/leonardo-portfolio.git
   ```

2. **Aceder à pasta:**
   ```bash
   cd leonardo-portfolio
   ```

3. **Instalar dependências:**
   ```bash
   npm install
   ```

4. **Executar em modo de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. **Gerar build para produção:**
   ```bash
   npm run build
   ```

6. **Pré-visualizar o build:**
   ```bash
   npm run preview
   ```

---

## 🧩 Personalização

- Edita as secções e textos em `src/components/`:
  - `Header.jsx` → menu de navegação e nome;
  - `About.jsx` → descrição pessoal e foto;
  - `Projects.jsx` → lista de projetos com links reais;
  - `Skills.jsx` → tecnologias dominadas;
  - `Contact.jsx` → email, formulário e redes sociais.

## ☁️ Deploy

### **GitHub Pages**
1. Instala a dependência:
   ```bash
   npm install gh-pages --save-dev
   ```
2. Adiciona ao `package.json`:
   ```json
   "homepage": "https://seu-usuario.github.io/leonardo-portfolio",
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
3. Faz o deploy:
   ```bash
   npm run deploy
   ```

### **Alternativas:**
- **Vercel:** [https://vercel.com](https://vercel.com)
- **Netlify:** [https://netlify.com](https://netlify.com)
